# Introducción a Firefly Graph

Si ya has usado una herramienta de IA generativa, probablemente estés acostumbrado a escribir un mensaje, obtener un resultado y empezar de cero la próxima vez que necesites algo similar. Firefly Graph funciona de forma diferente. En lugar de un único mensaje, se crea un gráfico: un flujo de trabajo visual, paso a paso, donde cada entrada, transformación y salida se conecta y se guarda conjuntamente. Esta página te guía por todo lo que necesitas para crear tu primer gráfico: los conceptos básicos, un flujo de trabajo paso a paso en primer lugar y una biblioteca de plantillas listas para usar que puedes abrir y adaptar de inmediato.

>[!TIP]
>
>Piense en ello como una receta en lugar de una sola comida. Una vez que hayas creado un gráfico, puedes pasarlo a mano, volver a ejecutarlo en nuevas entradas o cambiar un paso y dejar que todo se actualice en sentido descendente automáticamente.
