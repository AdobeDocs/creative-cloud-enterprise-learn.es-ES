# Bullet Time VFX

Aprende a alimentar un producto principal o una imagen determinada para crear una secuencia giratoria de ángulos a su alrededor y, a continuación, unir el barrido del marco congelado automáticamente. [Abrir plantilla VFX de tiempo de viñeta](https://firefly.adobe.com/graph/edit/id/urn:aaid:sc:US:3efb4f51-345d-58eb-b7c8-7b289f0dd1c4).

[!BADGE Ejemplos del sector]{type=Informative tooltip="Ejemplos del sector"}

* **Al aire libre**: haz la foto de un héroe con una bala de un escalador en movimiento para un anuncio social de pago, sin una plataforma multicámara en el lugar.
* **Retail**: crea una instantánea de un marco congelado de 360 grados de una nueva zapatilla para la página de lanzamiento de un producto.
* **Automoción**: genera una foto de héroe giratoria de un vehículo para una sala de exposición digital, sin una sesión de estudio de plataforma giratoria.

>[!TIP]
>
>**Antes de comenzar**: para obtener los mejores resultados, personaliza esta plantilla para adaptarla a tu propia marca, producto y flujo de trabajo. Intercambie las imágenes de referencia, los mensajes y la copia antes de utilizar cualquier salida.
